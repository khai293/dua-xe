# V8 integration contract
All modules native ESM; no production external dependency. index.html loads src/main.js. Canvas2D 2.5D using true OSM world positions. No gamepad auto steer. Root owns main.js, assets and integration.

## data.js (engine agent)
export async loadData() -> {geo, tracks, levels, vehicles, story}. geo from assets/haiphong-osm.json. tracks[i] has original OSM points and name etc plus length resampling optional. Export helpers as needed.
## engine.js (engine agent)
export class GameEngine extends EventTarget. constructor(data, storage=localStorage). engine.save contains version=8, unlocked 1..5,wins,best,totalCarries,badges,affection,gifts,settings. Exports save load migration optional.
Methods: start({mode:'story'|'custom',track:0..9,level:0..4,vehicle:0..3,laps:1..3,difficulty:0.9,opponent:'lucien',weather:'clear',time:'day'}), update(dt,input), pause(), resume(), rescue(), setEnvironment(time,weather), previewCutscene(kiss=false), skipCutscene(), continueAfterCarry(), restart(), toMenu(). input={throttle:0..1,brake:0..1,steer:-1..1,tuck:boolean}.
State engine.state: {phase:'menu'|'countdown'|'race'|'paused'|'cutscene'|'result', config, track (preprocessed with points,length etc), player:{x,y,heading,speed,lean,steer,progress,lap,checkpoint}, rivals:[{x,y,heading,speed,progress,id}], elapsed,countdown,lap,laps,rank,obstacles:[{id,x,y,radius,type:'cone'|'crate'|'barrier',hit:boolean}], pickups:[{id,x,y,radius,collected:boolean}], checkpoints:[{x,y,radius,...}], checkpointIndex,nextTurn:{distance,angle,street},warning, cutscene:{elapsed,preview,kiss,reason,stage},result:{won,time,position,valid,carried}, cameraMode (0/1/2), environment:{time:'day'|'sunset'|'night',weather:'clear'|'rain'|'fog'}, stats:{collisions,lightHits,...}}. Renderer may handle missing fields until race loaded.
Events engine.dispatchEvent(new CustomEvent('change',{detail:{type,...}})) types state,finish,carry,pickup,collision,toast. main redraws HUD each rAF. Engine methods are source of truth, no DOM side effects. Fixed step update with dt in seconds in main.
engine.debug optional intentional test helpers behind query ?test=1; core correctness tests directly use methods and manipulate state, no hidden production auto-drive.
## renderer.js (render agent)
export class Renderer constructor(canvas,data), async load(), resize(), render(state,dt=1/60), drawMap(canvas,track,player?) optional; root can implement map. load reads assets/manifest.json if present. Art available later at /assets/*.png. Root sends paths & atlas layout.
Canvas world projection: true player x,y heading in radians (heading = atan2(dy,dx), heading 0 points +x). User input steers world; render perspective chase or isometric default must permit reading turns, scenic districts and both riders; choose coherent 2.5D. Full track ribbon, safety barriers, checkpoint gates, spectators, storefronts. No character built of geometry if sprite available. Sprite atlas assigned later. Environment tint consistent. Avoid massive per-frame allocations, cull distance, quality controls. engine state.config.quality low/high/ultra, renderer.quality optional.
